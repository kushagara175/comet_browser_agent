# Domain Skill: Wikipedia (`wikipedia.org`)

## Overview
Domain playbook for Wikipedia encyclopedia navigation, topic search, and reference verification.

## Routes
- Main Portal: `/wiki/Main_Page`
- Article Search: `/wiki/Special:Search`
- Random Article: `/wiki/Special:Random`

## Key Landmarks
- `Search Wikipedia`: Article search input
- `Contents`: Table of contents / directory
- `Random article`: Discovery navigation link

## Metrics
- `references_count`: Number of verified citations and references
