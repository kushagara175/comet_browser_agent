# Domain Skill: Search Engines (DuckDuckGo & Google)

## Overview
Domain playbooks for private and global web search execution and result ranking.

## DuckDuckGo (`duckduckgo.com`)
- **Routes**: `/`, `/settings`
- **Landmarks**: `Search without being tracked` (input), `Clear` (button)
- **Metrics**: `results_count`

## Google Search (`google.com`)
- **Routes**: `/`, `/search`, `/preferences`
- **Landmarks**: `Search` (input `q`), `Google Search` (button), `I'm Feeling Lucky` (button)
- **Metrics**: `search_results_count` (estimated count from result stats)
