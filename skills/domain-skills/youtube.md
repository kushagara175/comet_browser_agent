# Domain Skill: YouTube (`youtube.com`)

## Overview
Domain playbook for YouTube video searching, playback, and channel metrics.

## Routes
- Search Results: `/results`
- Subscriptions: `/feed/subscriptions`
- Trending: `/feed/trending`
- Home Feed: `/`

## Key Landmarks
- `Search`: Search input box (`name="search_query"`)
- `Subscribe`: Channel subscribe button
- `Like`: Like button
- `Play` / `Pause`: Player controls toggle

## Metrics
- `views`: Video view count
- `subscribers`: Channel subscriber count
